This curl tutorial tells us about using of curl from the command line in order to interact with the internet without using the Browser OR simply by our terminal.
Here, I created a simple http server using express and in order to test whether the server is working fine, I did not check it from the Browser. I did it from my terminal using curl.
I made a GET request using curl to my localhost using the command "curl -X GET http://localhost:3000" instead of going to the browser and do it manually.
